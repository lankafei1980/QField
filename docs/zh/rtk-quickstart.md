# RTK 外业助手（QField 中文化定制版）使用手册

本 App 基于 [QField](https://github.com/opengisch/QField) 4.3.8 定制：界面简体中文、内置 NTRIP 差分客户端、为 SparkFun RTK 系列与千寻位置（FindCM）账号做了适配，并可与官方 QField 同时安装。

- 包名：`cn.zpyzs.rtkapp`
- 架构：`arm64-v8a`（绝大多数 2018 年后的安卓手机/平板）
- 最低系统：Android 8，建议 Android 10 及以上

---

## 1. 安装

1. 从 GitHub Actions 的构建产物里下载 `rtkapp-arm64` 附件中的 APK。
2. 手机连电脑执行 `adb install -r rtkapp-*.apk`；或把 APK 传到手机后点击安装（需在系统里允许“安装未知来源应用”）。
3. 首次启动会依次申请：定位、蓝牙、相机、存储（视工程需要）。**蓝牙和精确定位必须允许**，否则搜不到接收机。

> 与官方 QField 共存：包名不同、签名不同，互不覆盖；桌面图标名称是「RTK 外业助手」。

## 2. 连接 SparkFun RTK 接收机

SparkFun RTK（Facet / Express / Surveyor 等）通过**经典蓝牙 SPP** 输出全量 NMEA（GGA/GSA/GST/GSV/RMC），默认 2–4 Hz、115200 波特；QField 通过同一个蓝牙串口把 RTCM 差分数据回写给接收机。

1. 接收机开机，等它完成定位（面板上出现卫星/RTK 状态）。
2. 手机 **系统设置 → 蓝牙** 里搜索并配对，设备名通常形如 `SparkFunRTK Facet`，配对码 **1234**。
3. 打开 App：**设置（齿轮）→ 定位 → 定位设备 → 添加**
   - 类型选 **蓝牙 BT + BLE (NMEA)**
   - 点「扫描附近设备」，列表里 GNSS 类设备会排在前面
   - 选中你的 SparkFun 设备，命名（如“SparkFun Facet”）后保存
4. 回到定位页，点「连接到 SparkFun Facet」，等状态变成“已连接”，定位面板开始刷新经纬度、卫星数、精度。

**USB 连接（可选）**：用 OTG 线接手机时，选「串口 (NMEA)」类型；本版本串口同样支持接收 NTRIP 差分并回写给接收机。

**判断是否真的拿到了 RTK**：看 GGA 的质量位——

| 质量位 | 含义 |
|---|---|
| 1 | 单点（未差分，米级） |
| 2 | 码差分（亚米级） |
| 4 | **RTK 固定解（厘米级）** |
| 5 | RTK 浮点解（分米级） |

## 3. 使用千寻账号（FindCM）

前提：已连上 SparkFun（或其它支持回写差分的接收机），并且手机有移动网络。

1. **设置 → 定位 → 打开「启用 NTRIP 校正」**
2. 点右边的调节按钮进入 **NTRIP 设置**：
   - **服务商** 选「千寻位置 FindCM」→ 自动填入
     - 地址 `rtk.ntrip.qxwz.com`
     - 端口 `8003`
     - 挂载点 `AUTO`
     - 勾选「向 caster 转发位置」
   - **用户名/密码**：填千寻给你的**差分账号**与密码（不是手机号登录密码）
   - 端口按需要的坐标框架选：

     | 端口 | 坐标框架 | 参考历元 |
     |---|---|---|
     | 8001 | ITRF2008 | 2016.0 |
     | 8002 | WGS84 | 2005.0 |
     | 8003 | CGCS2000 | 2000.0 |

   - 挂载点 `AUTO` 让服务端按你上报的位置就近选站；若开通资料里指定了具体挂载点（如 `RTCM32_GGB`），直接手填覆盖 `AUTO` 即可
3. 返回定位页，确认开关为开；状态提示会依次变成「正在连接」→「已连接」，并显示 ↑↓ 字节数。
4. 十来秒内 GGA 质量位应变为 4（RTK 固定解）。

**状态指示**（地图右上角定位信息里的圆点）：蓝色＝正常；橙色＝10 秒没收到差分数据；灰色＝已关闭。

**断线自动重连**：网络抖动、切基站、隧道出来后，客户端会按 5、10、20、40、60 秒退避自动重连；账号密码错误这类 4xx 错误不会重复重试，避免把账号踢下线。

## 4. 坐标系与成果

- 千寻端口决定**改正数所用的坐标框架**；工程最终坐标由 QGIS 工程的坐标系决定。
- 常用工程坐标系：
  - `EPSG:4490` CGCS2000 地理坐标
  - `EPSG:4547` CGCS2000 / 3-degree Gauss-Kruger CM 114E（按测区中央经线选 4547–4554 或带号版本）
- **天线高**：设置 → 定位 → 天线高补偿，填接收机相位中心到地面的斜高/垂高（按你的作业规范）。
- **高程**：默认使用接收机报告的椭球高经坐标转换得到的高程；如需精确正常高，在工程里配置高程格网改正（设置 → 定位 → 高程格网改正）。

## 5. 常见问题

| 现象 | 排查 |
|---|---|
| 蓝牙列表里没有 SparkFun | 接收机是否开机；是否已在系统蓝牙里配对（PIN 1234）；蓝牙是否被别的 App 占用（如 SW Maps 仍在后台连接） |
| 连上了但没坐标 | 接收机是否在输出 NMEA（SparkFun 菜单里确认协议为 NMEA）；换个 NMEA 波特率/协议试试 |
| NTRIP 报 401 | 账号/密码错误或套餐到期；注意填的是差分账号 |
| NTRIP 报找不到挂载点 | 挂载点名称写错（大小写敏感）；先把挂载点改成 `AUTO` 试 |
| NTRIP 一直正在连接 | 手机网络能否访问 `rtk.ntrip.qxwz.com`（可用 `tools/dev/qxwz_probe.py` 在电脑上先验证）；是否开了限制性 VPN |
| 一直单点解 | 端口与坐标框架不匹配、账号无覆盖、或接收机未收到 RTCM（看 ↑ 字节数是否在涨） |
| 坐标整体偏移几十米 | 千寻端口与工程坐标系不匹配（例如用了 8002 WGS84 却按 CGCS2000 出图） |

## 6. 无硬件自测（开发用）

见 `tools/dev/README.md`：用本地模拟 NTRIP caster + 模拟 NMEA 源即可验证定位链路、差分下发与断线重连，不需要真实接收机与千寻账号。
