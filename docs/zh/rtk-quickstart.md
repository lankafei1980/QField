# RTK 外业助手（QField 中文化定制版）使用手册

本 App 基于 [QField](https://github.com/opengisch/QField) 4.3.8 定制：界面简体中文、内置 NTRIP 差分客户端、为 SparkFun RTK 系列与千寻位置（FindCM）账号做了适配，并可与官方 QField 同时安装。

- 包名：`cn.zpyzs.rtkapp`
- 架构：`arm64-v8a`（绝大多数 2018 年后的安卓手机/平板）
- 最低系统：Android 8，建议 Android 10 及以上

---

## 1. 安装

1. 从 GitHub Actions 的构建产物里下载 `rtkapp-arm64` 附件中的 APK。
2. 手机连电脑执行 `adb install -r rtkapp-*.apk`；或把 APK 传到手机后点击安装（需在系统里允许“安装未知来源应用”）。
3. 首次启动会依次申请：定位、蓝牙、相机、存储（视工程需要）。**蓝牙和精确定位必须允许**，否则搜不到接收机。

> 与官方 QField 共存：包名不同、签名不同，互不覆盖；桌面图标名称是「RTK 外业助手」。

## 2. 连接 SparkFun RTK 接收机

SparkFun RTK（Facet / Express / Surveyor 等）通过**经典蓝牙 SPP** 输出全量 NMEA（GGA/GSA/GST/GSV/RMC），默认 2–4 Hz、115200 波特；QField 通过同一个蓝牙串口把 RTCM 差分数据回写给接收机。

1. 接收机开机，等它完成定位（面板上出现卫星/RTK 状态）。
2. 手机 **系统设置 → 蓝牙** 里搜索并配对，设备名通常形如 `SparkFunRTK Facet`，配对码 **1234**。
3. 打开 App：**设置（齿轮）→ 定位 → 定位设备 → 添加**
   - 类型选 **蓝牙 BT + BLE (NMEA)**
   - 点「扫描附近设备」，列表里 GNSS 类设备会排在前面
   - 选中你的 SparkFun 设备，命名（如“SparkFun Facet”）后保存
4. 回到定位页，点「连接到 SparkFun Facet」，等状态变成“已连接”，定位面板开始刷新经纬度、卫星数、精度。

**USB 连接（可选）**：用 OTG 线接手机时，选「串口 (NMEA)」类型；本版本串口同样支持接收 NTRIP 差分并回写给接收机。

**判断是否真的拿到了 RTK**：看 GGA 的质量位——

| 质量位 | 含义 |
|---|---|
| 1 | 单点（未差分，米级） |
| 2 | 码差分（亚米级） |
| 4 | **RTK 固定解（厘米级）** |
| 5 | RTK 浮点解（分米级） |

## 3. 使用千寻账号（FindCM）

前提：已连上 SparkFun（或其它支持回写差分的接收机），并且手机有移动网络。

1. **设置 → 定位 → 打开「启用 NTRIP 校正」**
2. 点右边的调节按钮进入 **NTRIP 设置**：
   - **服务商** 选「千寻位置 FindCM」→ 自动填入
     - 地址 `rtk.ntrip.qxwz.com`
     - 端口 `8003`
     - 挂载点 `AUTO`
     - 勾选「向 caster 转发位置」
   - **用户名/密码**：填千寻给你的**差分账号**与密码（不是手机号登录密码）
   - 端口按需要的坐标框架选：

     | 端口 | 坐标框架 | 参考历元 |
     |---|---|---|
     | 8001 | ITRF2008 | 2016.0 |
     | 8002 | WGS84 | 2005.0 |
     | 8003 | CGCS2000 | 2000.0 |

   - 挂载点 `AUTO` 让服务端按你上报的位置就近选站；若开通资料里指定了具体挂载点（如 `RTCM32_GGB`），直接手填覆盖 `AUTO` 即可
3. 返回定位页，确认开关为开；状态提示会依次变成「正在连接」→「已连接」，并显示 ↑↓ 字节数。
4. 十来秒内 GGA 质量位应变为 4（RTK 固定解）。

**状态指示**（地图右上角定位信息里的圆点）：蓝色＝正常；橙色＝10 秒没收到差分数据；灰色＝已关闭。

**断线自动重连**：网络抖动、切基站、隧道出来后，客户端会按 5、10、20、40、60 秒退避自动重连；账号密码错误这类 4xx 错误不会重复重试，避免把账号踢下线。

## 4. 坐标系与成果

- 千寻端口决定**改正数所用的坐标框架**；工程最终坐标由 QGIS 工程的坐标系决定。
- 常用工程坐标系：
  - `EPSG:4490` CGCS2000 地理坐标
  - `EPSG:4547` CGCS2000 / 3-degree Gauss-Kruger CM 114E（按测区中央经线选 4547–4554 或带号版本）
- **杆高**：按工程保存，在主屏右侧状态卡 → 校正配置里填写（对中杆 + 天线相位中心偏移）。设置 → 定位 → 天线高补偿只作为**新建工程的默认值**。
- **高程**：默认使用接收机报告的椭球高经坐标转换得到的高程；如需精确正常高，在工程里配置高程格网改正（设置 → 定位 → 高程格网改正）。

## 5. 常见问题

| 现象 | 排查 |
|---|---|
| 蓝牙列表里没有 SparkFun | 接收机是否开机；是否已在系统蓝牙里配对（PIN 1234）；蓝牙是否被别的 App 占用（如 SW Maps 仍在后台连接） |
| 连上了但没坐标 | 接收机是否在输出 NMEA（SparkFun 菜单里确认协议为 NMEA）；换个 NMEA 波特率/协议试试 |
| NTRIP 报 401 | 账号/密码错误或套餐到期；注意填的是差分账号 |
| NTRIP 报找不到挂载点 | 挂载点名称写错（大小写敏感）；先把挂载点改成 `AUTO` 试 |
| NTRIP 一直正在连接 | 手机网络能否访问 `rtk.ntrip.qxwz.com`（可用 `tools/dev/qxwz_probe.py` 在电脑上先验证）；是否开了限制性 VPN |
| 一直单点解 | 端口与坐标框架不匹配、账号无覆盖、或接收机未收到 RTCM（看 ↑ 字节数是否在涨） |
| 坐标整体偏移几十米 | 千寻端口与工程坐标系不匹配（例如用了 8002 WGS84 却按 CGCS2000 出图） |

## 6. 无硬件自测（开发用）

见 `tools/dev/README.md`：用本地模拟 NTRIP caster + 模拟 NMEA 源即可验证定位链路、差分下发与断线重连，不需要真实接收机与千寻账号。

## 7. 在线底图（NEWGIS）与新建工程

**设置 → 底图**：

1. 服务器填 `https://gis.lankafei1980.top:5443`（默认已填）
2. 填 NEWGIS 的账号密码 → **连接**
3. 连接成功后会出现：
   - 底图：天地图矢量 / 矢量注记 / 影像 / 影像注记、吉林一号卫星影像；服务端开启谷歌开关时还会多一项 **谷歌卫星影像**
   - 正射影像：服务器上每幅 COG 一张（`正射影像：<文件名>`）
4. 打开开关即叠加到地图；**按住滑块左右拖动**即可连续调透明度（松手保存，换工程/重启后保留）；选择会记住，换工程也会自动恢复

**新建工程时**：创建页面「选择底图」里，除了彩色/深灰/浅灰/空白/自定义，还会多出「天地图矢量 / 天地图影像 / 吉林一号」；服务端开启谷歌开关时再多一项「谷歌卫星影像」（连过服务后才出现），直接选它即可把在线底图写进新工程。

说明：
- 天地图的 tk 由服务器 `/api/sys-config` 下发，不用手填；
- 吉林一号是 TMS 瓦片，App 里已按 `{-y}` 处理；
- 服务器用私有 CA（mkcert），App 已内置该根证书，无需在手机上装证书；
- 正射影像走 TiTiler，单幅影像面积大，建议只开需要的区域；
- 谷歌卫星影像走服务器同源 `/gmap` 反代，由服务端 `basemap_google_enabled` 开关控制，**默认关闭**；该端点仅供内部比对，对外发布/商用请改用天地图或吉林一号。打开「设置 → 底图」时 App 会自动刷新一次目录，服务端开关变化后无需手动点「重新加载图层」。

## 8. 其他 CORS 账号（移动 / 电信 / 联通）与「粘贴自动填写」

除了千寻，NTRIP 设置里新增了 **中国移动 CORS** 预设（地址 `120.253.239.161`、端口 `8001`（CGCS2000）、接入点 `RTCM33_GRCEJ`）。

更省事的方式是**直接粘贴运营商发来的开通短信**：

1. 设置 → 定位 → 启用 NTRIP 校正 → 调节按钮
2. 在「粘贴账号信息」框里整段粘贴（保留原文即可），点 **自动填写**
3. App 会自动识别并填入：账号、密码、服务器地址、端口、接入点

识别是**按关键字模糊匹配**的，不绑定某一家卖家的排版（各家短信格式都不一样）：

| 识别项 | 认可的关键字（缺冒号也行） |
|---|---|
| 用户名 | 账号 / 帐号 / 账户 / 用户名 / 用户 / account / user |
| 密码 | 密码 / 口令 / password / passwd / pwd |
| 服务器 | IP / 地址 / 域名 / 主机 / 服务器 / server / host；也兜底取文中第一个 IPv4 |
| 端口 | 端口 / port；多个端口按后面的坐标系注解选，**优先 CGCS2000** |
| 接入点 | 接入点 / 挂载点 / 源节点 / mount point；也兜底取文中第一个 `RTCM33_xxx` 这类标识 |

另外：文本里出现「千寻」或「移动」会自动先套用对应预设，再用粘贴内容里的地址/端口/接入点覆盖；「或」分隔的多个 IP 取第一个。

> 注意：不同运营商的端口对应坐标系不同——中国移动是 8001=CGCS2000、8002=WGS84；千寻是 8001=ITRF2008、8002=WGS84、8003=CGCS2000。选错端口会让坐标整体偏移。

## 9. 测点、杆高与校正（本版新增）

主屏右下角的绿色加号就是**测点按钮**，按钮上方显示中文解状态：固定解（绿）/浮点解（黄）/差分解（黄）/单点解（红）/搜星中（红）/无定位（灰）；采样时切换为「采集中」。

**数据源**：点要素测点始终取 GNSS 实测坐标；「跟随」开关只控制地图是否居中，拖动地图后不会再变成屏幕靶标。

### 9.1 采集质控（系统级，所有工程共用）

设置 → 定位 → **GNSS采集质控**：

- 采集必须为固定解（默认开）
- 平面精度限值 HRMS / 高程精度限值 VRMS（默认 0.02 m / 0.04 m；填 0 表示不限制）
- 采样超时时间（默认 60 秒）
- 采样平均次数 1 / 3 / 5（默认 5；按 1 Hz 采样，5 次约 5 秒）
- 允许强制采集（应急）

不达标时用中文说明原因；如果是差分没连、账号没配，提示条上的「去设置」可直接跳到定位页。

### 9.2 杆高（工程级）

主屏右侧状态卡第二行「杆高：1.6m」，点开「校正配置」即可修改。杆高默认 1.6 m、保留一位小数；配置弹窗里还有 **1.6 m / 1.8 m** 两个快捷按钮。杆高按工程保存，切换工程自动切换。

### 9.3 坐标校正（工程级）

点状态卡第一行进入「校正配置」：

- **单点平移校正**：1 个控制点，求 dX / dY / dH
- **多点四参数校正**：≥2 个控制点，最小二乘解 4 参数（比例、旋转、平移）
- **高程**：跟随平面校正（取控制点高差均值）或独立高程改正（手填）
- 控制点的实测坐标可用「采集当前坐标」，按同一套质控参数采集（不套用现有校正）
- 【开始解算】后状态卡显示「单点校正 / 多点校正」；【重置校正参数】只清校正参数，杆高与控制点保留

> 校正只作用于测点落点，不改变地图上的实时定位光标。
## 10. 图层顺序（本版新增）

图例（我的工程 → 图例）里的图层顺序现在会自动整理：

- **正在绘制的图层**（或它所在的顶层图层组）临时提到最上层，退出采集后自动还原；
- **底图**按固定层级从下到上：卫星/影像类（天地图影像、吉林一号、谷歌）→ 正射影像 → 天地图矢量底图 → 矢量注记；
- **工程自己的图层**（注释、管线、测点等）保持原有相对顺序，永远在底图之上。

底图开关变化、打开工程、重新加载底图目录都会自动归位；图例标题栏的「整理」按钮可随时手动再整理一次，并提示「图层顺序已整理」。

> 只调整 App 注入的在线底图；工程文件里自带的影像/图层保持工程原顺序。若工程启用了 QGIS 的「自定义图层顺序」，App 会改用图层树顺序（关闭自定义顺序），否则分级置底不会生效。
