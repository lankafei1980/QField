## C. 模拟链路（无硬件）

1. 电脑：`tools/dev/run_mocks.sh`，记下它打印的 IP。
2. App：定位设备 → 添加 → **TCP (NMEA)** → 填 `IP:2102` → 保存 → 连接。
   - [ ] 定位面板开始刷新，约 4 次/秒
   - [ ] 卫星数 14、水平精度约 0.7（模拟值）
   - [ ] 地图定位光标在地图上移动（模拟源坐标缓慢漂移）
3. App：设置 → 定位 → 启用 NTRIP 校正 → 调节按钮：
   - **服务商** 选「自定义」→ 主机 `IP`、端口 `2101`、挂载点 `AUTO`、协议 NTRIP Revision 1、用户名/密码 `demo`
   - [ ] 返回后状态显示「NTRIP 客户端连接」→「已连接」
   - [ ] ↑↓ 字节数持续增长
   - [ ] 电脑终端能看到 `stream started` 和 `GGA received: …` 计数（说明 App 在回传位置）
   - [ ] 电脑终端能看到 `RTCM 1005 / 1074 / …` 由模拟接收机解析出来（说明差分被写回接收机）
4. 断线重连：等 caster 主动断链（脚本里 90 秒一次）
   - [ ] 状态短暂变断开 → 5 秒左右自动重连 → 再 10/20 秒（若连续失败）
   - [ ] 恢复后 ↑↓ 字节数重新增长
5. 负向用例（验证错误提示是中文且不无限重试）：
   - 把挂载点改成 `NOPE` 重启脚本（脚本接受任意挂载点，所以改要求用户名错）
   - 把密码改错 → 应提示「**NTRIP 认证失败，请检查用户名和密码（HTTP 401）**」且**不**反复重连
6. 千寻连通性（不需要账号）：
   - 电脑 `python3 tools/dev/qxwz_probe.py` → 三个端口都返回 `HTTP 401 Unauthorized`
   - App 里把服务商切到「千寻位置 FindCM」→ 主机/端口/AUTO 自动填好；账号随便填 → 应得到同一个 401 中文提示（说明 App 在本机网络下能打到千寻）

## D. 真机硬件（等你拿到 SparkFun / 千寻账号）

- [ ] 系统蓝牙配对 SparkFun（PIN 1234）→ App 扫描列表里它能出现且排在前面
- [ ] 连接后定位面板出坐标；GGA 质量位 1（单点）
- [ ] 千寻：服务商选千寻、端口 8003、挂载点 AUTO、填差分账号密码 → 开关打开
- [ ] 10–20 秒内质量位变 **4（RTK 固定解）**，水平精度进入厘米级
- [ ] 已知点比对：与已知坐标差 < 3 cm（固定解、天线高正确设置）
- [ ] 拔掉网络再恢复 → 自动重连并回到固定解

## E. RTK 测点 / 杆高 / 校正 / 质控

准备：打开一个点图层，进入采集模式；主屏右下角出现绿色加号，按钮上方有小字状态。

1. 数据源
   - [ ] 关闭跟随，把地图拖走 200 m 以上，准星仍固定在 GNSS 位置（不跳到屏幕中心）
   - [ ] 此时测点保存的坐标与定位信息面板坐标一致（差 ≤ 2 cm）
   - [ ] 打开/关闭跟随，只改变地图是否居中，不改变落点

2. 状态文字
   - [ ] 固定解（绿）/ 浮点解（黄）/ 差分解（黄）/ 单点解（红）/ 搜星中（红）/ 无定位（灰）
   - [ ] 采样时显示「采集中」

3. 质控
   - [ ] 设置 → 定位 → GNSS采集质控：6 项中文，改完重启 App 仍保留，切工程不丢
   - [ ] 浮点解 + 勾选「采集必须为固定解」→ 点测点按钮提示「解状态不合格或精度超限，无法采集」，且不保存要素
   - [ ] 未启用 NTRIP → 提示「未启用差分服务，无法固定解」，点「去设置」能跳到定位页
   - [ ] 采样 5 次 → 环形进度走到 100% → 保存 1 个点；采样期间连点按钮无效
   - [ ] 遮挡天线直到超时 → 进度环变红 +「采样超时，采集失败」，没有新要素

4. 杆高与校正
   - [ ] 主屏右侧两行：第一行「单点校正/多点校正/高程改正/无校正」，第二行「杆高：1.6m」，点击打开校正配置
   - [ ] 校正配置里杆高默认 1.6、只保留一位小数；点 1.6 m / 1.8 m 快捷按钮能立即切换
   - [ ] 工程 A 杆高 1.8、工程 B 杆高 1.6：切换工程后状态卡与保存点的 Z 相差 0.2 m
   - [ ] 单点校正：1 个控制点，已知-实测差被精确加到落点（≤1 cm）
   - [ ] 四参数：3 个控制点解算，状态显示「多点校正」，残差 RMS 显示正常
   - [ ] 重置校正参数 → 状态「无校正」，杆高保持不变
   - [ ] 地理坐标系工程 → 解算时提示「当前工程为地理坐标系，无法使用平面校正」

5. 全中文
   - [ ] 上述流程中没有 Fixed / Float / DGPS / Single 等英文状态词
